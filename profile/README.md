## Synaptech in open source

Some of the tools we build for our work are published here as open source.
They're maintained alongside the business, so replies and reviews can take a
while, but every issue and pull request gets read.

- **Spec first.** We do the research and planning before writing code. Each
  project plans its work with [OpenSpec](https://github.com/Fission-AI/OpenSpec)
  or [agent-skills](https://github.com/addyosmani/agent-skills), and the plans
  live in the repository, so you can see what's coming before you contribute.
- **Contributions welcome.** Look for issues labeled `good first issue` or
  `help wanted`, and read the
  [contributing guidelines](https://github.com/Synaptech-Solutions-SAS/.github/blob/main/CONTRIBUTING.md)
  before you start.
- **AI-assisted work is accepted**, as long as you understand it, verify it,
  and disclose it.
- **Found a vulnerability?** Don't open a public issue. Follow the
  [security policy](https://github.com/Synaptech-Solutions-SAS/.github/blob/main/SECURITY.md)
  to report it privately.
